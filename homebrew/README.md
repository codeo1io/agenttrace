# homebrew-tap

Homebrew tap for [agenttrace](https://github.com/codeo1io/agenttrace) — AI Agent Session Analyzer.

## Install

```bash
brew tap codeo1io/tap
brew install agenttrace
```

## Update

```bash
brew upgrade agenttrace
```

Formulas in this tap are auto-updated by GitHub Actions on every `v*` tag push to [codeo1io/agenttrace](https://github.com/codeo1io/agenttrace).
