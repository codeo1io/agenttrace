## Reusable lessons / prevention rules

- **Sanitize at the producer, not per render site.** rm-1400's one-seam fix at `symlink_target_of` covered two call sites and the render; a per-site fix would have left the second call site live. Generalizes to every `read_link`/`fs::read` → TEXT-render path.
- **Recorded-cost precedence is a family, not a one-off.** rm-1399 wired into the existing rm-436/RecordedCostBasis discipline with zero new model vocabulary — new sources of upstream-reported cost should join that family, not invent provenance.
- **Gate assertions rotted against a moving pin are check-staleness, not product bugs.** rm-051: install.sh was correct; the check hardcoded v0.9.0. Prefer deriving the expected ref from the source of truth.
- **A gate that needs a repo-local binary silently fails when the binary was built privately.** check-docs-commands rc1 resolved to "build target/release first". Gates should honor `AGENTTRACE_BIN` uniformly or fail loudly on a missing binary.
- **Fleet-environment hazards (this box):** (a) EITHER filesystem can fill — root (/tmp) or sdb (/home/agent, symptom: `as: BFD assertion fail elf.c` in build scripts); fallback is `CARGO_TARGET_DIR=/var/tmp/<attempt>`; (b) `/home/agent/.cache/at-*` dirs with minute-old mtimes are ACTIVE sibling runs — never reap them as stale; (c) shared `conductor-cargo-target` gets clobbered mid-run by siblings — always build in a private target dir; (d) spool `-scratch` dirs and `/tmp/at-*` backups get reaped within hours — mirror run-critical substrates to `/home/agent/.cache/at-<purpose>-<attempt8>/` AND re-verify at consumption (this cycle's roadmap band had to be REGENERATED for exactly this reason).
- **Numeral/fog discipline worked.** Live census before minting (walls + spool postimages) kept the band collision-free: 1395/1396 → 966bd5f9, 1397/1398 → f8ca87d1, this cycle 1399/1400, next free 1401.
